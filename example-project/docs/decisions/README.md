# Architecture Decision Records

One short file per significant decision that is hard to reverse: why we chose X over Y. The point is that a future session (human or AI) does not reopen a settled question, or does so knowingly.

Create a new record with the `adr` skill (it loads on its own when a decision is made) or by copying [.claude/skills/adr/template.md](../../.claude/skills/adr/template.md).
